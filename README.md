## 📋 Características

- **Design Minimalista**: Interface limpa e elegante com estética preto e branco
- **Modo Escuro/Claro**: Alternância entre temas com transições suaves
- **Animações Refinadas**: Feedback visual com micro-interações e animações sutis
- **Responsividade Total**: Adaptação perfeita para qualquer dispositivo
- **Feedback Tátil**: Resposta visual instantânea ao interagir com os botões
- **Histórico de Cálculos**: Registro das operações realizadas
- **Precisão Numérica**: Cálculos precisos com tratamento adequado de decimais
- **Acessibilidade**: Suporte a navegação por teclado e leitores de tela

## 🔧 Tecnologias Utilizadas

- HTML5 semântico para estrutura
- CSS3 com variáveis para temas e animações
- JavaScript para lógica de cálculo e interações
- jQuery para manipulação do DOM e animações
- LocalStorage para persistência de preferências
- Técnicas avançadas de CSS para efeitos visuais
- Layout baseado em CSS Grid e Flexbox

## 🚀 Como Usar

1. Acesse a [calculadora online](https://calculadora-marcelo.netlify.app)
2. Utilize o mouse ou o teclado para interagir:
   - Números (0-9) para entrada de dígitos
   - Operadores (+, -, *, /) para operações básicas
   - Enter ou "=" para calcular resultado
   - Backspace para apagar último dígito
   - Delete ou "C" para limpar tudo
   - "T" para alternar entre temas claro/escuro
